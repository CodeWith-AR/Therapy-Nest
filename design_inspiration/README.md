# Design Inspiration & Design System Specifications

This folder contains the clinical UX/UI guidelines, neuro-accessible design tokens, and interaction specifications for **Therapy Nest**.

## 🎨 Contents

- **`DESIGN-claude.md`**: Master clinical design system guide covering color palettes, cognitive load minimization, and typography.
- **`design-2.md`**: Component hierarchy, spacing scales, and elevation tokens.
- **`designV3.md`**: Modern Material 3 neuro-friendly design specifications with high-contrast color token mapping.
- **`skill-2.md`** & **`skillV3.md`**: Detailed workflow guides for creating new exercise widgets with tremor-tolerant touch targets ($\ge 48\times 48\text{ dp}$) and auditory reinforcement cues.
