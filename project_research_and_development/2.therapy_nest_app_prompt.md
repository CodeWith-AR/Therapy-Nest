```
Continue building Therapy Nest. Module 2: Baseline Assessment.

The baseline assessment seeds each patient's initial ability estimate (θ) per domain.
Without this, the adaptive engine has no starting point (cold-start problem).

## CLINICAL BASIS
Adapted from the Western Aphasia Battery (WAB-R) subscales — 4 core areas:
1. Spontaneous Speech / Word Finding (Language domain)
2. Auditory Comprehension (Comprehension domain)
3. Repetition (Speech domain)
4. Naming (Language domain)

Plus cognitive screens:
5. Visual Memory (Memory domain)
6. Attention (Attention domain)

## ASSESSMENT STRUCTURE
- 5–10 items per domain (short — must be completable in ~10 minutes total)
- Multi-modal: tap, match, spoken (if microphone permission granted)
- Each item scores 0 or 1 (binary for initial IRT seeding)
- At the end, θ is initialized per domain:
    θ_initial = (score_fraction × 4.0) - 2.0   // maps 0→-2, 0.5→0, 1.0→2

## ASSESSMENT ITEMS BY DOMAIN

### Domain 1: Language / Naming (10 items)
- Show picture, user selects correct word from 4 options (multiple choice)
- Items: common objects (apple, car, chair, door, pen, cup, clock, shoe, tree, phone)
- Difficulty pre-seeded: items 1-3 b=-1.5, items 4-7 b=0, items 8-10 b=1.5

### Domain 2: Auditory Comprehension (8 items)
- TTS reads a word/phrase, user selects matching picture from 4 options
- Items: simple nouns → 2-step commands
- Hint available: replay audio (counts hint usage)

### Domain 3: Memory (8 items)
- Show sequence of 3–5 colored shapes for 3 seconds, then hide
- User selects the correct sequence from 3 options
- Difficulty: sequence length (3→5 items)

### Domain 4: Attention (6 items)
- Show grid of symbols, user finds and taps specific target
- Timed (response_time_ms captured)

### Domain 5: Speech / Repetition (6 items — only if mic permission granted)
- TTS speaks a word, user repeats it
- Vosk transcribes → fuzzy match against target
- Score: exact match = 1, phoneme similarity > 0.7 = 0.5, else 0

### Domain 6: Math (6 items)
- Simple number recognition → clock reading
```

```
Continue building Therapy Nest. Module 3: Core Exercise Engine.

This is the CENTRAL module — the engine that runs ALL therapy sessions. Every other exercise 
module (Memory, Attention, Language, Speech, Reading, Math) plugs into this engine.

## EXERCISE SESSION FLOW
1. DOMAIN SELECTION → User selects 1+ domains for today's session
2. ITEM SELECTION → Adaptive engine picks next item (Elo-style ability matching)
3. ITEM PRESENTATION → Exercise widget renders based on task_type
4. RESPONSE CAPTURE → Touch, speech, drag, or typed input
5. IMMEDIATE FEEDBACK → Correct/incorrect animation + TTS feedback
6. CUEING (if wrong) → Graduated hint sequence
7. θ UPDATE → Ability estimate updated via Elo formula
8. NEXT ITEM → Repeat until session goal reached
9. SESSION COMPLETE → Summary screen with stats

## ADAPTIVE ITEM SELECTION (Elo-style IRT)

double expectedSuccess(double theta, double itemDifficulty) {
  return 1.0 / (1.0 + pow(10, (itemDifficulty - theta) / 400));
}

double updateTheta(bool correct, double theta, double itemDifficulty) {
  const double K = 32.0;
  double expected = expectedSuccess(theta, itemDifficulty);
  double outcome = correct ? 1.0 : 0.0;
  return theta + K * (outcome - expected);
}
// θ clamped to [-3.0, 3.0]
// Item selection targets expected_success ≈ 0.75

## CUEING HIERARCHY (Clinical Standard)
When a user answers incorrectly, provide graduated assistance:
- Level 0: no cue (item presented normally)
- Level 1 (semantic): "It's something you use to..." — text only
- Level 2 (phonemic): "It starts with the letter 'C'" — text only
- Level 3 (visual): Show first letter or partial image
- Level 4 (full model): Speak/show correct answer → user repeats

Scoring with cues:
- Correct at level 0 → partial_score = 1.0
- Correct at level 1-2 → partial_score = 0.7
- Correct at level 3-4 → partial_score = 0.3
- No response after level 4 → partial_score = 0.0
```

```
## ADAPTIVE ENGINE (adaptive_engine.py)

import math

K_FACTOR = 32.0
THETA_MIN = -3.0
THETA_MAX = 3.0
TARGET_SUCCESS_RATE = 0.75

def expected_success(theta: float, difficulty: float, discrimination: float = 1.0) -> float:
    """2-Parameter Logistic IRT model"""
    return 1.0 / (1.0 + math.exp(-1.702 * discrimination * (theta - difficulty)))

def update_theta_elo(theta: float, difficulty: float, is_correct: bool,
                     partial_score: float = None, hint_count: int = 0) -> float:
    expected = expected_success(theta, difficulty)
    outcome = partial_score if partial_score is not None else (1.0 if is_correct else 0.0)
    k_adjusted = K_FACTOR * (1.0 - (hint_count * 0.15))
    new_theta = theta + k_adjusted * (outcome - expected)
    return max(THETA_MIN, min(THETA_MAX, new_theta))

def select_items(theta: float, available_items: list, seen_this_week: set,
                 count: int = 10) -> list:
    """Select items targeting 75% success rate"""
    scored = []
    for item in available_items:
        b = item['difficulty']
        a = item.get('discrimination', 1.0)
        p = expected_success(theta, b, a)
        information = (a ** 2) * p * (1 - p)
        freshness = 0.3 if item['id'] not in seen_this_week else 0.0
        distance = abs(p - TARGET_SUCCESS_RATE)
        score = information + freshness - distance
        scored.append((score, item))
    scored.sort(key=lambda x: x[0], reverse=True)
    return [item for _, item in scored[:count]]
```

```
  Future<void> syncPendingAttempts()  // batch max 50, mark synced after

  // Called on session start (while online)
  Future<void> prefetchExercises(List<String> domains)  // 50 items per domain

  // Start listening to connectivity changes
  void startListening()
}

## OFFLINE STRATEGY
- Download: 50 items per domain on first login = 350 items total
- Images: lazy-download + cache in app directory (~17MB total)
- Refresh: re-download domain cache each session when online
- Expiry: items expire after 7 days, re-download when online

## STORAGE BUDGET
- Exercise JSON: ~350 items × 5KB = ~1.75MB
- Images: ~350 × 50KB compressed = ~17MB
- Total: ~20MB (fine for 32GB devices)

## CONNECTIVITY BANNER (core/widgets/connectivity_banner.dart)
- Offline: subtle "Offline mode — syncing when connected" banner
- Syncing: green dot + "Syncing..." status
- Non-blocking: therapy continues offline seamlessly

## CONFLICT RESOLUTION
- θ updates: take higher value if server and local diverge (more generous)
- Attempts: append-only, no conflicts
- Sessions: preserve local ID, server assigns on sync
```

```
### Streak Logic
int computeCurrentStreak(List<DateTime> sessionDates) {
  if (sessionDates.isEmpty) return 0;
  int streak = 0;
  DateTime checkDate = DateTime.now();
  for (final date in sessionDates.reversed) {
    if (checkDate.difference(date).inDays <= 1) {
      streak++;
      checkDate = date;
    } else break;
  }
  return streak;
}
```
